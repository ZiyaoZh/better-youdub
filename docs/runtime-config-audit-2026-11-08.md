## 故障原因与修复

容器已安装 `audiostretchy 1.3.14`，该版本提供 `audiostretchy.core.stretch_audio`，不再提供旧的 `audiostretchy.stretch` 模块。原代码的旧导入路径失败后，被包装成“依赖未安装”的报错。

修复优先使用 `core` 接口，并兼容旧版 `stretch` 接口；导入失败时保留原始错误信息。GPU 镜像构建增加实际生成 WAV 并调用应用拉伸逻辑的检查，避免只验证包安装成功而遗漏接口兼容性。

运行容器应用相同代码修复，并为修复前已启动的 worker 提供旧模块兼容入口。修复后的 `better-youdub:gpu` 镜像已构建；为保留正在执行的任务，当前容器通过原地修复继续运行。

验证：30 项 TTS、任务配置及 TTS 质量测试通过；运行容器中的真实 WAV 拉伸检查通过；GPU 镜像构建中的相同检查通过。
